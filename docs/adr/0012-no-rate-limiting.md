# ADR-0012: 不做反作弊 / 限频

**状态**: Accepted
**日期**: 2026-08-28
**决策者**: 产品负责人

## 背景

公网应用,搜索/下载事件被记录。是否需要防刷?

候选:
- (a) 不限
- (b) 按 IP 限频
- (c) 全局总限频
- (d) 验证码

## 决策

**本期不做任何限频或反作弊(选项 a)。**

## 理由

- **产品定位**:辅助下载工具,事件数据只用于展示榜单,不参与定价、不参与商业决策;刷榜的唯一后果是榜单"看起来奇怪",无直接经济损失。
- **公网常态**:VSCodeMarket 自身不持有二进制,被刷量不会爆磁盘(100MB/天 量级,90 天 几个 GB,可控)。
- **简化优于完备**:限频会引入 IP 池维护、验证码用户体验成本。当前阶段不值。

## 后果

- 排行榜可能有"水货",但榜单数据保留时间短(90 天清),影响有限。
- SQLite 容量增长需关注(详见 ADR-0011 容量估算)。
- 运营侧定期人工 spot check 榜单合理性。

## 何时升级(触发条件)

任一发生即起新 ADR 评估:
- SQLite 文件 > 5GB
- 单日 INSERT 速率 > 100K/天
- 出现明显的商业损失或法律投诉
- 第三方镜像/竞品引用本榜单数据做商业决策

## 替代方案

- **(b) IP 限频**:留作升级路径,不本期做。
- **(d) 验证码**:永远不做(违背零摩擦定位)。
