# ADR-0007: 下载链接基于 User-Agent 推断 + 用户手动覆盖

**状态**: Accepted
**日期**: 2026-08-28
**决策者**: 产品负责人 + 前端

## 背景

需求描述:"最利于当前 IP 适合的下载链接"。

实际可解释为:

- (a) 基于请求者 IP 解析地理位置,选最近 CDN
- (b) 基于请求者 User-Agent 默认选 PlatformBuild,用户可手动改
- (c) 完全让用户手动选
- (d) 基于登录信息/部门选内网镜像源

## 决策

**采用 (b):UA 推断默认 PlatformBuild + 用户可在表单内手动改。**

## 理由

- VSCode 官方 CDN(`download.visualstudio.com` 等)已自动就近调度,**不需要**服务端做地域路由——做了反而引入错误风险。
- UA 推断能给到 80% 用户正确默认值,显著减少点击次数。
- 保留手动覆盖以应对 UA 不准确或用户主动选其他平台的场景。

## 后果

- 后端新增 `/api/ua-infer`(或同义):根据请求 UA 返回 PlatformBuild 推断结果。前端在加载时调用一次,填入表单默认值。
- 前端版本查询表单始终可见 Platform / Architecture / Channel 三个字段,用户可任意修改。
- 不做 IP 地理位置解析、不接第三方 IP 库。
- **UA 不入库**:仅在 `/api/ua-infer` 端点内做 PlatformBuild 推断,推断完成后丢弃原始 UA,事件表(ADR-0010)只存 IP + CountryCode,不存 UA。

## 替代方案

- **(a) IP 路由**:否决。CDN 已就近调度,叠加 IP 路由只会增加错误概率。
- **(c) 纯手动**:否决。UX 差,违背"便利工具"定位。
- **(d) 内网镜像源**:否决。本项目部署在公网,不假设用户有内网镜像。
