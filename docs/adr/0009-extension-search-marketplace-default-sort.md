# ADR-0009: 扩展搜索采用 Marketplace 默认排序

**状态**: Accepted
**日期**: 2026-08-28
**决策者**: 产品负责人

## 背景

扩展搜索结果排序策略:

- (a) Marketplace API 返回的默认排序(下载量 + 官方加权)
- (b) 按 downloadCount 降序
- (c) Publisher 优先 + 下载量
- (d) 字母序

## 决策

**采用 (a):Marketplace 默认排序。**

## 理由

- 这是用户在 marketplace.visualstudio.com 上看到的顺序,**最符合用户心智模型**。
- 官方加权已经平衡了"高质量小众插件"与"流行插件",自己重新排序容易引入偏差。

## 后果

- 后端扩展搜索请求透传 Marketplace 的 `sortOrder` 参数,默认不指定。
- 前端不展示排序切换控件。如确需,届时新立 ADR。
- 后端不做二次排序、做一次简单的相关性去重。

## 替代方案

- **(b/c/d) 自定义排序**:否决。理由如上。
