# ADR-0003: 公网部署,完全公开,无鉴权

**状态**: Superseded by ADR-0010
**原日期**: 2026-08-28
**决策者**: 产品负责人
**取代说明**: 引入"完整日志 + IP + 地区统计"后,后端必须记录用户行为日志用于热门榜单与地区维度统计。原"不写访问日志"决策被推翻,详见 ADR-0010。

## 背景

VSCodeMarket 部署位置和访问控制策略未定。

候选:

- (a) 内网部署 + 完全公开
- (b) 内网部署 + 仅访问日志
- (c) 内网部署 + 简单登录
- (d) 内网部署 + 完整用户系统(LDAP/SSO)
- (e) 公网部署 + 完全公开

## 决策

**VSCodeMarket 部署在公网,完全公开,无鉴权、无访问日志、无用户系统(选项 e)。**

## 理由

- **真实业务场景**:用户从公网下载后拷入内网使用。VSCodeMarket 自身只是"找直链"的便利工具,不持有任何敏感数据。
- **零合规负担**:不存用户数据,不存下载记录,免 GDPR / 等保审计。
- **零运维成本**:无密码管理、无 LDAP 集成、无密码轮换。
- **与上游一致**:`update.code.visualstudio.com`、`marketplace.visualstudio.com` 本身都是公开服务,VSCodeMarket 是它们的前置聚合层。

## 后果

- 所有功能对匿名访客开放。
- 不存 PII、不存日志、不存 cookie(除必要的会话/UI 偏好外)。
- 如未来要统计 PV/UV,起 ADR-0011 单独评估。
- 拒绝在 PR 中加入用户系统、登录页面、密码字段。

## 替代方案

- **(a/b/c/d) 内网部署 + 鉴权**:否决。与"公网辅助下载"的定位不符。
