# /constitution 提示语

> 用法:将本文件正文整块喂给 `/constitution` 命令,生成的章程落盘到 `constitution.md`。
> 引用基础:`CONTEXT.md`、`docs/adr/0001~0013`。

---

为项目 vscodemarket 制定开发章程 (constitution.md)。

章程只承载**不可妥协的治理性原则**(每条须可执行、可验收,可在 PR 评审中作为通过/驳回依据)。产品需求事实归 spec.md,技术栈与实施步骤归 plan.md,ADR 单独管理具体决策。

4 条原则:

1. **公网应用属性**:服务部署公网,服务对象是任意公网访客(非内网员工)。所有涉及用户数据、行为追踪、错误日志的决策须以 GDPR/个保法/CCPA 等公网合规边界为准绳。

2. **官方直链原则**:所有下载地址必须是官方官方域名上的资源链接。后端**不代理、不缓存、不重写**下载流量,仅做"找直链"与"聚合"工作。任何把本站演化为镜像、CDN、下载代理的改动直接驳回。

3. **辅助脚本零网络原则**:页面提供的一切"内网部署辅助脚本"必须只含运行/安装命令(例如启动服务、安装扩展、解压包),不得包含 wget/curl/Invoke-WebRequest 等任何下载动作。用户拷入内网后,脚本的所有行为必须可离线执行。

4. **极简立场**:对一切"主动防御 / 重型基础设施 / 跨域追踪"默认拒绝。当前未启用限频、反作弊、验证码、用户系统、独立文档站;任何 PR 试图引入上述能力,必须在 ADR 中给出**触发条件与替代方案对比**后由维护者批准方可合入。
